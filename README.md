# 個人資料修改申請書

壽險保單「聯絡資訊變更」申請書自動填寫工具。變更後的地址、電話、E-mail 只輸入一次，
自動對好各家保險公司申請書的欄位，輸出 PDF。

**線上使用：** 開啟本 repo 的 GitHub Pages 網址即可（不用安裝）。

## 使用方式

1. 第一次使用先填「業務員」的登錄字號與聯絡電話（只存在自己的瀏覽器，下次會自動帶入）。
2. 填要保人姓名、身分證字號，以及**變更後**的住所、電話、E-mail（不改的留空）。
   住所輸入一整串即可（郵遞區號＋縣市＋鄉鎮區＋路街＋巷弄＋號＋樓），會自動拆成縣市／路／號等欄位。
3. 勾選要送的保險公司並填保單號碼（多張用「、」分隔）。某家不改某一項，取消那一家的「地址／電話／E-mail」勾選。
4. 按「產生申請書」，右邊預覽確認後下載單份 PDF 或「全部下載（zip）」。
5. 可「存成填寫資料.json」留存，之後補件或重印用「開啟填寫資料.json」載入。

填入的字、勾選、圈選一律為藍色；**填寫日期與所有簽名欄一律留空**。列印前請再檢查一次。

## 隱私

所有資料只在使用者自己的瀏覽器中處理，**不會上傳到任何伺服器**；客戶資料不會被保存，
關閉頁面即消失（只有業務員登錄字號與電話會存在該瀏覽器的 localStorage）。

## 維護

- 欄位座標在 `layout.json`（每家保險公司一段）。保險公司改版時，換掉 `forms/` 裡的空白申請書並更新座標。
- 各家「業務員單位」代號填在 `layout.json` 各公司的 `業務員單位`，有填就會自動代入（目前留空）。
- 填寫邏輯在 `fill-core.js`，與桌面版 `fill_personal.py` 共用同一份座標與規則。
